# PUBLIC DATA SEED POLICY

## Rule
Public web data may be used to create a **draft seed only**.

Do not treat public menu aggregators/social posts as production truth for:
- current price
- availability
- exact recipe
- exact outlet hours
- payment methods

## Seed workflow
1. collect public menu/category candidates
2. mark source/date in seed notes
3. load as draft data
4. replace/verify with actual Parangtritis data before production

## Suggested seed status
- DRAFT
- NEEDS_VERIFICATION
- VERIFIED_BY_OUTLET
- ACTIVE
