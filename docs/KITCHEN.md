# KITCHEN DISPLAY

## Goal
A kitchen screen optimized for speed, not analytics.

Columns/states:
- NEW
- PREPARING
- READY
- DONE/HANDED OFF

Order card should show:
- order number
- order type
- item names
- quantities
- notes
- elapsed time
- important modifiers

Kitchen cannot:
- change item price
- change payment amount
- access private customer payment secrets

## UX
- large touch targets
- high contrast
- one-tap status progression
- sound/visual attention cue when a new order arrives, with a mute option
- responsive enough for a tablet/Android device
